# IIS BSUIR Schedule — Telegram Mini App (TMA)

Кроссплатформенная веб-версия приложения «Расписание БГУИР» для Telegram Mini App и браузеров.

## Возможности

- **Расписание занятий**:
  - Интеграция с официальным API ИИС БГУИР (`https://iis.bsuir.by/api/v1`).
  - Поиск и выбор студенческих групп и преподавателей.
  - Фильтрация по подгруппам (1 / 2) и детальная информация о паре (аудитории, тип занятия, преподаватель, примечания).
  - Учебный календарь: автоматический расчет текущей недели (1..4) с 1 сентября.
  - Горизонтальная лента дат (Apple Date Rail) на 90 дней (-7 до +83 дней).

- **Apple Pull-to-Refresh**:
  - Пружинная анимация оттягивания.
  - Встроенный watchdog-таймер на 2.5 секунды для предотвращения зависания индикатора.
  - Защита от ложных срабатываний: инерция быстрого скролла вверх блокируется и не вызывает обновление.

- **Успеваемость**:
  - Средний балл, рейтинг группы и просмотр оценок по предметам семестра.

- **Заметки**:
  - Создание и сохранение персональных заметок и напоминаний к занятиям.

- **Стилизация и темы**:
  - Apple Minimal: плавные размытия, градиенты и плавающая панель навигации.
  - Cyber Techno: терминальный интерфейс, моноширинный шрифт и ASCII-элементы.
  - Настройка цветовых акцентов (Action Blue, Sky Blue, Spring Green, Rose Red, Techno Neon).

- **Адаптивность**:
  - Оптимизировано для смартфонов внутри Telegram, планшетов, ноутбуков и Telegram Desktop.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Elate11/telegram_shedule_bsuir.git
cd telegram_shedule_bsuir
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте пример конфигурационного файла:
```bash
cp .env.example .env
```
Укажите токен бота в файле `.env`:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```

### 5. Сборка проекта
```bash
npm run build
```
Готовые статические файлы сохраняются в папку `dist/`.
