# IIS BSUIR Schedule — Telegram Mini App (TMA)

Точная копия мобильного приложения «Расписание БГУИР» для Telegram Mini App.

## Особенности реализации:
- **100% соответствие дизайну и логике оригинала**:
  - Фирменная карточная система занятий (время, аудитория, тип предмета, преподаватель, подгруппы).
  - Apple Pull-to-refresh контейнер с защитой от случайных срабатываний при скролле снизу вверх и таймаут-сторожем на 2.5 секунды.
  - Горизонтальный Apple Date Rail с 90 днями (-7 дней до +83 дней) и автоматическим определением учебной недели БГУИР (1..4) по алгоритму от 1 сентября.
  - Экраны: «Расписание», «Оценки (Успеваемость)», «Заметки», «Профиль и сервисы».
  - Дизайн-системы: Apple Minimal и Cyber Techno (с терминальным шрифтом и неоновыми эффектами).
  - Палитра акцентных цветов: Apple Indigo, Sky Blue, Spring Green, Rose, Amber, Purple, Techno Neon.
  - Поддержка экранов любой ширины: мобильные телефоны, планшеты (iPad), ноутбуки и Telegram Desktop (с центрированием и ограничением контейнера `max-w-4xl`).
- **Связь с сервером**:
  - Реальные API-эндпоинты ИИС БГУИР (`https://iis.bsuir.by/api/v1`).
  - Локальное кэширование расписания в `localStorage` для мгновенной загрузки в офлайн-режиме.
- **Telegram WebApp SDK**:
  - Автоматическая адаптация под цвета темы Telegram.
  - Поддержка тактильного отклика (Haptic Feedback) через `Telegram.WebApp.HapticFeedback`.

## Запуск в разработке:
```bash
npm install
npm run dev
```

## Сборка:
```bash
npm run build
```
Готовая сборка находится в директории `dist/`.
